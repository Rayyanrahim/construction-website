# Florida Construction Venture — logo files

Navy `#193d59`, orange `#ed773b`. Font: DM Sans Bold (already converted to outlines in every file, so it isn't needed to open them).

## svg/ — vector, scales to any size

| File | Use |
| --- | --- |
| `logo.svg` | Main logo on white or light backgrounds |
| `logo-white.svg` | Logo on navy, dark or photo backgrounds |
| `icon.svg` | Symbol only (bars and arrow), navy |
| `app-icon.svg` | Navy square icon — favicon, app icon, social profile picture |

Open them in Illustrator, Figma, Inkscape or a browser. For print, send the SVG (or ask the printer which format they want).

## png/ — ready-made images, transparent background

- `logo-600.png`, `logo-1200.png`, `logo-2400.png` — main logo
- `logo-white-1200.png`, `logo-white-2400.png` — white version (transparent, so it looks blank on a white screen)
- `logo-on-navy-1200.png` — white version already on a navy background
- `icon-512.png`, `icon-1024.png` — symbol only
- `app-icon-180.png`, `app-icon-512.png` — navy square icon

The number is the width in pixels.

## logo.psd — Photoshop

9500 × 2500 px with separate layers: Background, Symbol (Bars, Chevron) and Name (FLORIDA, CONSTRUCTION VENTURE). Each layer can be moved, recoloured (Layer Style → Color Overlay) or hidden. The text layers are pixels, not editable type; to change the wording, retype it with DM Sans Bold.
